# xFontGauntlet v2.0

First branded release of authoritative G196 font test corpus. Original ZIP contains 195 groups, 2,768 declared cases, 43,289 files and 9,952 explicit directory entries. It preserves intentional unusual ZIP member paths, binaries, companions, test expectations, manifests, and tools.
